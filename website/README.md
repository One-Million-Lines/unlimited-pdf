# UnlimitedPDF website

A self-contained static one-page marketing site for the UnlimitedPDF Chrome extension. It uses plain HTML, CSS, and a small local JavaScript file with no build step and no external assets, fonts, scripts, or CDN dependencies.

## Preview locally

From this directory:

```sh
python3 -m http.server 8199
```

Then open <http://localhost:8199/> in a browser.

## Chrome Web Store URL

The `Add to Chrome` links currently point to `https://chromewebstore.google.com/` as a placeholder. Replace them with the real Chrome Web Store listing URL once the extension listing is live.
